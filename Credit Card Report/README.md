# 💳 Credit Card Financial Weekly Dashboard 📊

This Power BI project presents a comprehensive weekly dashboard for monitoring key financial metrics related to credit card usage. The dashboard enables stakeholders to track revenue, transactions, customer behavior, and regional trends using interactive visuals powered by SQL and DAX.

---

## 🚀 Project Objective

To build a data-driven, interactive dashboard that provides **weekly insights** into:
- Revenue performance
- Transaction volumes
- Customer demographics and behavior
- Card type trends
- Regional contribution
- Activation and delinquency rates

The report supports decision-makers by highlighting **week-over-week changes** and **year-to-date performance** in a clear, visual manner.

---

## 🗃️ Data Source

- Data ingested from structured **CSV files**
- Imported into a **SQL Server database**
- Processed and visualized using **Power BI**

**Key tables include:**
- `cust_detail` – Customer demographics and income
- `cc_detail` – Credit card transactions and revenue components

---

## ⚙️ Tools & Technologies

- **SQL Server**: For data storage and preprocessing
- **DAX (Data Analysis Expressions)**: For creating dynamic metrics like WoW growth
- **Power BI Desktop**: For data modeling and dashboard development
